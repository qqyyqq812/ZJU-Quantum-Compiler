\section{总结与局限}

本项目完成了一条面向受限量子硬件的神经辅助量子路由流程。项目首先把量子路由
建模为硬件耦合图上的映射与搜索问题，然后实现 NPQR：用神经网络评估候选 SWAP
动作，用初始映射选择提供较好的搜索起点，用有界束搜索保留多条候选路线，用前沿
触发和动作剪枝控制搜索规模，用局部后缀修复处理接近完成但卡住的路线，并用轨迹
复放验证最终电路。系统还提供命令行、REST API、MCP 服务和网页演示入口，能够
返回路由后电路、SWAP 数、深度、耗时、路线轨迹和 SABRE basic 基线对比。

本项目的核心结论可以概括为三点。第一，NPQR 已经不是一个只停留在离线训练或单个
脚本中的模型实验，而是一个可调用、可复验、可展示的完整路由系统。第二，在最终
代表性 10/20 比特评测中，NPQR 完成 $10/10$ 个样例，并且 $10/10$ 的 SWAP 数低于
SABRE basic；所有完成结果都不依赖 SABRE 回退路径，并通过轨迹复放验证。第三，
30/50 比特扩展测试进一步证明当前流程具备一定扩展能力：已声明的 $4/4$ 个
30/50 比特样例全部完成，并且全部优于 SABRE basic。基于这些证据，项目可以合理
宣称：在代表性评测场景和选定 50 比特结构上，NPQR 相对 SABRE basic 取得了
可复验的质量优势。

这些结果的意义不只是少数表格指标的提升。更重要的是，项目展示了一种适合组合优化
问题的神经辅助求解路线：神经网络不直接替代搜索，而是作为启发式评分函数嵌入可解释的
搜索框架。这样既保留了模型对复杂状态的表达能力，又保留了经典搜索在约束检查、
局部修复和失败边界上的可控性。从方法设计角度看，项目覆盖了图建模、变治法、贪婪
启发式、减治法、时空权衡、迭代改进、搜索剪枝、近似算法和神经网络推理等内容，
是 ``组合优化 + 神经启发式 + 工程验证'' 的完整案例。

项目也有清晰边界。首先，NPQR 的运行时间明显高于 SABRE basic，这是神经推理、
候选映射、束搜索和轨迹复放带来的工程成本；本项目以完成率和 SWAP 质量为主要
指标，不把速度超过 SABRE 作为结项目标。其次，NPQR 不应被表述为通用最先进量子
路由器，也不保证在所有电路上优于 SABRE。SABRE lookahead 不是本文主比较目标，
部分样例上仍可能更强。再次，80/100 比特实验已经暴露当前边界：LineGHZ80 在
240 秒 CPU 有界运行内未完成，100 比特样例没有作为最终能力声明。因此，当前已
证明的稳定上界应写作选定 50 比特结构，而不是任意 50 比特以上电路。

如果未来继续推进，最优方向不是盲目增加训练时间或直接启动 GPU，而是围绕大规模
路由瓶颈做结构性优化。第一，改进 topology-aware initial mapping，让大规模电路
从更合理的物理布局开始。第二，设计更强的 frontier candidate pruning，减少 50
比特以上搜索中的无效候选展开。第三，引入 profile selector，根据电路结构自动
选择轻量路由、前沿增强路由或分层搜索。第四，在 80/100 比特规模上探索
hierarchical routing，把全局路由拆成更小的拓扑区域再合并。只有当这些诊断证明
瓶颈主要来自模型排序能力时，才值得把 GPU 训练作为后续手段。

综合来看，本项目已经达到量子信息基础大作业的高质量结项标准：它有明确的问题建模，
有可解释的算法流程，有可运行的系统接口，有不依赖回退路径的复放证据，有相对
SABRE basic 的稳定 10/20 比特优势，也有选定 30/50 比特扩展结果和诚实的
80/100 比特边界。最终结论不是夸大为 ``全面超过所有路由算法''，而是更准确地说明：
NPQR 在代表性中小规模量子路由任务上形成了质量优于 SABRE basic 的神经辅助搜索
系统，并展示了继续扩展到更大规模的可行方向。
