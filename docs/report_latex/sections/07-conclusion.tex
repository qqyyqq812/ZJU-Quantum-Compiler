\section{总结与局限}

本项目实现了一个面向受限量子硬件的神经辅助量子路由编译器。项目把量子路由建模
为图约束下的映射与搜索问题，并设计了 NPQR 流程：用神经网络评估候选 SWAP 动作，
再结合初始映射选择、有界束搜索、前沿触发、动作剪枝、局部后缀修复和轨迹复放。
系统提供命令行、REST API、MCP 服务和网页演示入口，能够输出路由后电路、SWAP 数、
深度、耗时、轨迹和 SABRE 基线对比。

从课程角度看，项目覆盖了图问题、变治法、贪婪启发式、减治法、时空权衡、迭代
改进、搜索剪枝、近似算法和神经网络推理等内容。与只调用现成算法相比，NPQR 的
主要价值在于把学习模型嵌入可解释搜索框架，并通过工程接口形成可使用的完整流程。

项目仍有明确局限。首先，默认模型不应被表述为最先进量子路由模型；其次，NPQR
不保证在所有电路上优于 SABRE；再次，当前公开实验规模有限，尚不能证明大规模
泛化能力。后续工作可以从三方面推进：扩大固定基准集，改进神经网络训练目标，
以及系统评估不同搜索组件对完成率、SWAP 数和耗时的贡献。
