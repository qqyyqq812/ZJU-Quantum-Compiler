\section{引言}

量子计算程序在逻辑层面描述量子门序列，但真实量子芯片在物理层面存在连接约束。
例如，一个双比特门只能在相邻物理量子比特之间直接执行。当逻辑电路中的两个
量子比特被映射到不相邻的物理位置时，编译器需要插入 SWAP 门来移动量子态。
这些额外 SWAP 会增加门数和电路深度，进而影响噪声环境下的实际执行质量。

因此，量子路由是量子编译中的关键步骤。它的输入是量子电路和硬件拓扑，输出是
满足拓扑约束的等价电路。该问题既包含图上的最短距离、映射选择和路径规划，也
包含启发式搜索、局部改进和近似求解。若尝试穷举所有映射和 SWAP 序列，搜索空间
会随量子比特数和双比特门数量快速增长，难以在量子信息基础大作业或交互式系统中
直接使用。

本项目的目标是实现一个神经辅助量子路由编译器。项目没有把神经网络设计成直接
生成完整路由电路的黑盒模型，而是把神经网络放入经典搜索框架中，让模型在每个
状态下评估候选 SWAP 动作。这样既能体现神经启发式方法，也能保留图搜索和轨迹验证
带来的可解释性。完整流程还引入初始映射选择、束搜索、触发剪枝和局部修复，使
系统能够在有限时间内寻找可行且质量较高的路线。

本文围绕以下内容展开：首先给出量子路由问题的图模型和优化目标；随后介绍 NPQR
算法的各个组成部分；接着说明系统如何通过多种接口提供服务；最后基于已有证据
给出实验分析、复杂度分析、方法要点映射和项目局限。
