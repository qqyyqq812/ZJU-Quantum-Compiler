撰写。由于本文定位为课程项目报告，参考资料以方法背景和实现依据为主。

  \item A. Zulehner, A. Paler, and R. Wille. An Efficient Methodology for
  Mapping Quantum Circuits to the IBM QX Architectures. \textit{IEEE TCAD},
  2019.
  \item 项目公开算法证据、接口说明和示例运行结果。
\end{enumerate}
