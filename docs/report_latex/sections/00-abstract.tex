\section{摘要}

真实量子芯片通常只允许相邻物理量子比特直接执行双比特门，而逻辑量子电路往往
假设任意两个量子比特都可以交互。量子路由编译需要在保持电路语义等价的前提下，
选择逻辑到物理量子比特的映射，并插入必要的 SWAP 门，使电路满足目标硬件拓扑。
这一任务本质上是图约束下的组合优化问题：映射选择、局部交换、前沿门推进和
搜索剪枝会共同影响最终 SWAP 数、电路深度和编译耗时。

本项目实现了神经辅助量子路由流程 NPQR。NPQR 没有把神经网络作为直接生成完整
路由的黑盒，而是把神经动作评分嵌入可解释的经典搜索框架。系统先生成并排序初始
映射候选，再通过有界束搜索展开 SWAP 序列，并结合前沿触发、动作剪枝和局部后缀
修复提升完成率。最终结果必须经过轨迹复放验证，确认每一步门和 SWAP 都满足硬件
连接约束。SABRE basic 在本项目中只作为主要质量基线，不作为 NPQR 的隐藏回退路径。

最终评测给出三个层次的结论。第一，在代表性 10/20 比特电路上，NPQR 完成
$10/10$ 个样例，并且 $10/10$ 的 SWAP 数低于 SABRE basic；所有完成结果均通过轨迹
复放，且没有使用 SABRE 回退路径。第二，在 30/50 比特有界扩展测试中，NPQR 完成
$4/4$ 个已声明样例，并在这些样例上继续低于 SABRE basic，说明该流程不只适用于
小规模演示。第三，80/100 比特实验用于界定边界：当前 CPU 有界运行尚不能把这些
规模作为稳定完成能力声明。因此，本文的主张是：NPQR 已形成一个可运行、可验证、
可解释的神经辅助路由系统，在课程代表场景中稳定优于 SABRE basic，并展示出到
50 比特选定结构的扩展潜力；本文不声称其全面超过 SABRE lookahead，也不声称其是
最先进通用量子路由器。
