\section{实验与分析}

本节只使用项目已有公开证据和快速基线矩阵，不新增大规模训练或完整评测。实验
分析的重点是说明系统已经形成可运行闭环，并客观描述 NPQR 与 SABRE 的关系。

\subsection{基线设置}

SABRE 是量子路由领域常用的启发式基线。它根据当前前沿门和后续门的距离估计来
选择 SWAP，在实践中稳定性较好。项目使用 SABRE 作为对比对象，并在接口返回中
展示其 SWAP 数、深度和运行时间。

快速矩阵覆盖 GHZ5、QFT5 和 QFT10 三个示例，并比较 SABRE 的 basic、lookahead
和 decay 三种启发式配置。表 \ref{tab:quick-matrix} 给出本地复跑结果。该表
主要用于展示基线难度和启发式差异，不能推出 NPQR 对所有电路都更优。

\input{tables/quick_matrix.tex}

从结果可以看出，GHZ5 在目标拓扑上不需要额外 SWAP；QFT5 和 QFT10 的双比特门
更密集，需要插入更多 SWAP。对 QFT10，lookahead 配置比 basic 配置少插入 13 个
SWAP，说明考虑后续门的启发式对复杂电路有明显帮助。

\subsection{NPQR 闭环证据}

项目公开证据显示，NPQR 默认流程由神经动作评分、初始映射选择、有界束搜索、
前沿触发剪枝、局部后缀修复和轨迹复放组成。固定困难随机交互样例用于运行时
闭环检查：NPQR 能完成路由，报告 SWAP 数为 46，REST API 与 MCP 调用结果一致，
且 SABRE 不参与 NPQR 的路线生成。

该结果说明系统不是只停留在离线脚本或单一模型推理上，而是已经通过对外接口返回
可验证结果。更准确的结论是：当前项目完成了神经辅助路由流程的工程闭环；它尚不
支持“在所有电路上优于 SABRE”的强结论。

\subsection{结果边界}

当前证据支持以下结论：项目能提供默认 NPQR 路由接口；NPQR 结果经过轨迹复放；
SABRE 仅作为基线对比；系统适合作为图搜索和神经启发式结合的课程项目。当前证据
不支持以下结论：NPQR 在所有电路上优于 SABRE；默认模型是量子路由领域最先进模型；
单独神经网络已经可以替代映射选择、搜索和修复。
