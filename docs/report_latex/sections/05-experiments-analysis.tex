\section{实验与分析}

本节给出项目最终采用的证据链。评测目标不是把 NPQR 描述成所有量子电路上的最优
路由器，而是回答三个更具体的问题：第一，系统能否在代表性课程样例上稳定完成
路由；第二，在完成且可复放的前提下，NPQR 的 SWAP 数是否低于 SABRE basic；第三，
当问题规模扩大到 30/50/80/100 比特时，当前系统的可靠能力边界在哪里。这样的
评测口径能避免把单个成功样例扩大为通用结论，也能清楚说明算法的真实价值。

\subsection{基线与指标}

SABRE 是量子路由领域常用的传统启发式算法。项目使用 SABRE basic 作为主要对比
基线，因为它稳定、易复现，并能代表一个工程上常见的传统路由器。SABRE 在本报告
中只承担基线角色：它用于生成对照指标，不参与 NPQR 的路线生成，也不在 NPQR
失败时作为回退路径返回成功结果。

实验分析使用的主要指标如表 \ref{tab:metrics} 所示。完成状态和轨迹复放是底线
指标；一个结果只有在所有原始门都被执行、所有双比特门都满足硬件边约束、且复放
通过时，才被视为有效完成。在此基础上，SWAP 数用于衡量路由质量，电路深度和耗时
用于衡量工程代价。由于 NPQR 包含神经推理和束搜索，本文不把运行时间超过 SABRE
视为失败；时间结果主要用于界定可用范围和后续优化方向。

从表中可以看到，NPQR 在 10 个代表样例上全部完成路由，并且每个样例的 SWAP 数

\subsection{30/50 比特扩展测试}

为了检查系统是否只适用于 20 比特以内的小样例，项目还进行了 30/50 比特扩展
测试。该实验不是全面大规模基准，而是一个有界能力测试：它关注当前流程能否在
更大拓扑上完成选定样例，且完成结果是否仍具有质量优势。目标拓扑使用 30
比特和 50 比特网格，仍以 SABRE basic 作为对比。

\input{tables/scale_smoke.tex}

结果显示，NPQR 可以在已声明的 30/50 比特样例上完成路由。在 LineGHZ30、
Random30-d4、LineGHZ50 和 RingSparse50 上，NPQR 的 SWAP 数均低于 SABRE basic。
这说明当前流程已经具备超过 20 比特演示规模的有效工作区间，最大已证明完成并
优于 SABRE basic 的规模达到 50 比特。需要强调的是，这仍然是选定样例测试，
不能表述为所有 50 比特电路或所有大规模电路都全面优于 SABRE。

进一步的 80/100 比特探索用于界定当前上限，而不是作为成功声明。LineGHZ80 在

\subsection{综合分析}

最终实验支持以下结论：NPQR 是一条可运行的神经辅助量子路由流程；它在 10/20
比特代表电路上相对 SABRE basic 取得一致 SWAP 优势；它的结果经过轨迹复放验证，
且 SABRE 只作为对比基线，不参与 NPQR 路线生成。扩展测试还表明，该流程可以
运行到 30/50 比特，并在所测结构上保持优势。

从算法角度看，这些结果说明本项目的有效性主要来自组合设计，而不是单一模型能力。
初始映射减少了搜索起点错误，神经评分提供了动作偏好，有界束搜索避免了过早贪心，
前沿触发和动作剪枝控制了复杂样例的候选展开，后缀修复补齐了接近完成的路线，
轨迹复放则保证了结果可审计。若只保留其中任一部分，系统很难同时做到完成、低
SWAP 和可验证。

实验也保留明确边界。首先，NPQR 的运行时间明显高于 SABRE，原因是它包含神经
推理、候选映射、前沿搜索和复放验证。其次，NPQR 并不保证能在 80/100 比特规模
完成路由，当前 CPU 有界测试已经观察到 80 比特 completion 边界。再次，SABRE
lookahead 不是本文的主比较目标，部分样例上 lookahead 仍可能取得更低 SWAP。
综合来看，本项目的合理结论是：NPQR 在代表性 10/20 比特场景中实现了对 SABRE
basic 的稳定质量优势，并把已证明扩展能力推进到选定 50 比特结构；50 比特
以上的任务仍需要进一步的初始映射、候选剪枝和分层搜索优化。
