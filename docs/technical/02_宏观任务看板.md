## 2. 两个大作业的统一定位

本项目同时服务两个目标：

1. 量子电路课程大作业：复杂拓扑结构下的量子电路 AI 编译与动态路由优化。
2. 算法设计与智能计算大作业第一部分：算法设计、编程实现、复杂度分析和
   5 分钟课堂展示。

统一题目建议为：

> 面向 NISQ 量子芯片拓扑约束的量子电路路由算法设计与智能优化

报告和展示应围绕四条算法主线组织：

- 量子路由建模：逻辑电路 DAG、物理耦合图、mapping、SWAP 动作和目标函数。
- SABRE 启发式基线：look-ahead greedy search，用作强 baseline。
- RL/GNN 路由器：MDP、状态特征、动作 mask、奖励函数和策略网络。
- V15 AlphaZero-style 扩展：PUCT MCTS、policy-value network 和 self-play。

## 6. 验证命令

当前推荐的收口验证命令：

```bash
.venv/bin/python -m pytest -q tests -s
.venv/bin/python -m py_compile src/cli.py src/server/app.py scripts/eval_mqt_bench.py
bash run_teacher_eval.sh
git diff --check
```

注意：当前环境中 `pytest -q` 默认 capture 曾在退出阶段触发临时文件异常；
使用 `-s` 能稳定得到测试结果。最近一次有效结果为 `82 passed, 1 skipped`。
