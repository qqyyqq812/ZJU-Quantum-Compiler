教程

从选择电路开始。

高级入口

维护者 REST API

普通用户不需要部署。页面默认调用项目方部署的 FastAPI REST 后端；维护者可用 URL 参数覆盖。网页里的 SABRE 基准固定为 Qiskit 默认 basic；高级 REST 直连仍兼容显式 heuristic 参数。

网页操作说明见 使用说明（Playground user guide）；这里保留部署和调试入口。

当前地址

uvicorn src.server.app:app --host 0.0.0.0 --port $PORT
?api=https://your-api.example
uvicorn src.server.app:app --reload --port 8765
?api=http://127.0.0.1:8765

API 不可用时，页面只显示简短错误；公开页面不会自动探测访问者电脑上的本地服务。

MCP 工具

MCP `/mcp` 保留给高级客户端和审阅流程，不是第一屏主入口。

qcompiler-mcp-http
uvicorn src.server.mcp_app:app --host 0.0.0.0 --port $PORT
POST /mcp
compile_qasm

输入 OpenQASM 2，返回 NPQR 路由后的 QASM。

compile_npqr

用 NPQR 编译项目内置示例。

compile_sabre

用 SABRE 编译项目内置示例。

list_examples

列出可用 QASM 示例。

qcompiler_status

查看项目状态和 NPQR 边界。

get_benchmarks

读取公开基准和声明边界。

get_npqr_boundary

查看 NPQR 能力、基准角色和不声明内容。

get_algorithm_evidence

课程展示用算法组件摘要。
