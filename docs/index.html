Advanced 高级入口

维护者 REST API

普通用户不需要部署。页面默认调用项目方部署的 FastAPI REST 后端；维护者可用 URL 参数覆盖。网页里的 SABRE baseline 固定为 Qiskit default/basic；高级 REST 直连仍兼容显式 heuristic 参数。

网页操作说明见 Playground user guide；这里保留部署和调试入口。

当前 endpoint

uvicorn src.server.app:app --host 0.0.0.0 --port $PORT
?api=https://your-api.example
uvicorn src.server.app:app --reload --port 8765
?api=http://127.0.0.1:8765

API 不可用时，页面只显示简短错误；公开页面不会自动探测访问者电脑上的本地服务。
