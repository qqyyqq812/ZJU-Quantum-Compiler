Service Interfaces REST API / MCP Server

REST API

浏览器调用项目部署的 FastAPI 服务；URL 参数 `?api=` 可覆盖目标地址。

当前地址

POST /api/validate校验 OpenQASM 与目标拓扑容量。
POST /api/compile/jobs创建真实编译任务，返回阶段状态。
GET /api/compile/jobs/{id}轮询解析、映射、路由、输出阶段。
POST /api/compile同步编译入口，保留脚本兼容。

MCP Server

MCP 面向工具客户端和自动化流程，使用同一套编译能力，不作为普通浏览器首屏路径。
