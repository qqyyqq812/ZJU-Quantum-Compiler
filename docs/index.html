本地 API

页面请求 http://localhost:8765/api/compile。 GitHub Pages 不能运行 Python，所以必须先启动本地服务。 

uvicorn src.server.app:app --reload --port 8765

项目边界

  • 默认硬件是 IBM Tokyo 20Q，inline 输入限制 8000 字符。
  • SABRE 使用 seed=42 和 trials=1。
  • AI router 只作为研究证据保留，公开默认路径仍是 SABRE。
